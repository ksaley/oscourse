## 3. UEFI BootServices и RuntimeServices. Совместимость с ОС

### ✅ Оценка: **ОЧЕНЬ ХОРОШО** (8.5/10)

**Сильные стороны:**
- Корректное разделение BootServices и RuntimeServices
- Правильное описание процесса SetVirtualAddressMap()
- Точное описание calling convention (RCX/RDX/R8/R9 для x86-64)
- Правильное понимание переключения в 32-битный режим (GD_KD32)
- Корректное описание Virtual Address Change Event
- Правильное понимание сохранения Runtime памяти

**Соответствие коду проекта:**
Проверено по `Bootloader.c` и `VirtualMemory.c`:
- ✅ GetMemoryMap() - реализовано
- ✅ ExitBootServices() - вызывается с MapKey
- ✅ SetupVirtualAddresses() - заполняет VirtualStart для runtime регионов
- ✅ SetVirtualAddressMap() - вызывается после ExitBootServices
- ✅ TranslateVirtualAddresses() - обработчик EVT_SIGNAL_VIRTUAL_ADDRESS_CHANGE
- ✅ efi_call_in_32bit_mode() - переключение сегментов на GD_KD32
- ✅ ConvertPointer() - используется для обновления указателей

**Замечания и неточности:**

1. **TPL для Runtime Services:**
   - ❌ **НЕТОЧНОСТЬ**: Утверждение "Runtime Services могут вызываться из прерываний, ОС должна использовать правильный TPL (обычно TPL_APPLICATION или TPL_NOTIFY)"
   - ✅ **ПРАВИЛЬНО**: Runtime Services НЕ могут вызываться из прерываний (IRQ). Они могут вызываться только из контекста приложения или уведомлений (TPL_APPLICATION, TPL_NOTIFY, TPL_CALLBACK), но НЕ из TPL_HIGH_LEVEL (уровень прерываний).
   - В коде используется TPL_NOTIFY для события виртуального адреса, что корректно.

2. **Атрибуты кэширования:**
   - ✅ Корректно упомянуты EFI_MEMORY_UC/WC/WT/WB
   - ⚠️ Можно добавить, что ОС должна устанавливать эти атрибуты в page table entries (PTE_PCD, PTE_PWT)

3. **Порядок операций:**
   - ✅ Последовательность верна: GetMemoryMap → ExitBootServices → SetupVirtualAddresses → SetVirtualAddressMap
   - ✅ Правильно указано, что MapKey необходим для ExitBootServices

4. **ConvertPointer:**
   - ✅ Корректно упомянут в контексте Virtual Address Change Event
   - В коде используется для обновления всех указателей в LoaderParams

**Рекомендации для улучшения:**
1. Уточнить ограничения TPL для Runtime Services
2. Добавить информацию о том, что Runtime Services код должен быть в памяти с атрибутом EFI_MEMORY_RUNTIME
3. Можно упомянуть, что после SetVirtualAddressMap все указатели на Runtime Services должны быть обновлены через ConvertPointer
